## Домашние задания

⚠️ Сданные задачи в семестре являются верхней границей оценки на устном экзамене.

Планируется **7 задач для решения в семестре**.

Первая задач оценивается в **1 балл**.
Каждая следующая задача оценивается максимум в **1.5 балла**.

Штрафы за просрочку:

- после мягкого дедлайна: **–10% каждые два дня вплоть до 50%**
- после жёсткого дедлайна: **Задачу сдать возможности не предоставляется**

Максимум за все Задачи: **10 баллов**.

### Формат сдачи ДЗ
- Прохождение тестов
- Прохождение код-ревью
- Прохождение устной защиты
